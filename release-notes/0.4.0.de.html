inlaut 0.4.0

  • Aufnahmen transkribieren: Der neue Menüpunkt „Datei transkribieren …“ wandelt eine Audio- oder Videodatei in Text um, zum Beispiel den Mitschnitt einer Besprechung. Das Ergebnis erscheint in einem eigenen Fenster, auf Wunsch mit Zeitmarken, und lässt sich kopieren oder sichern. Zehn Minuten Aufnahme dauern wenige Sekunden.
  • inlaut öffnet dafür alles, was macOS lesen kann (MP3, M4A, WAV, MP4, MOV und mehr), und WebM-Aufnahmen aus dem Browser. Die Datei bleibt auf deinem Mac. Das Transkript wird nur gespeichert, wenn du es sicherst.
  • Neue Einstellung „Aufnehmen mit“: Mit „Automatisch“ nimmt inlaut das Mikrofon des Mac, solange ein Bluetooth-Headset verbunden ist, denn Headsets brauchen über eine Sekunde, bis sie aufnehmen. Du kannst auch die Auswahl von macOS übernehmen oder ein bestimmtes Mikrofon festlegen.
