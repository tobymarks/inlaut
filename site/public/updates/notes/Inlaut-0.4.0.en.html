inlaut 0.4.0

  • Transcribe recordings: the new menu item “Transcribe File …” turns an audio or video file into text, for example the recording of a meeting. The result appears in its own window, with time stamps if you like, and can be copied or saved. Ten minutes of audio take a few seconds.
  • inlaut opens everything macOS can read (MP3, M4A, WAV, MP4, MOV and more) and WebM recordings from the browser. The file stays on your Mac. The transcript is only stored if you save it.
  • New setting “Record with”: with “Automatic”, inlaut uses the Mac’s own microphone while a Bluetooth headset is connected, because headsets take over a second to start recording. You can also follow the macOS setting or pick one microphone.
