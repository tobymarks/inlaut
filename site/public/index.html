Sprechen. Loslassen.
Der Text steht da

Inlaut ist eine kleine Menüleisten-App zum Diktieren auf dem Mac. Taste halten, sprechen, loslassen – der Text erscheint dort, wo dein Cursor steht, in jeder App. Erkannt wird auf deinem Mac. Nichts verlässt ihn.

Download folgt bald Quellcode auf GitHub

Kostenlos und Open Source (GPL-3.0). Für Macs mit Apple Silicon und macOS 26 oder neuer.

Nur auf deinem Mac

Kein Konto, keine Cloud, nichts wird gespeichert. Das Mikrofon ist nur offen, solange du diktierst.

Deutsch zuerst

Ein auf Deutsch trainiertes Parakeet-Modell versteht Fachbegriffe und Anglizismen deutlich besser als die eingebaute Diktierfunktion.

Sofort da

Zehn Sekunden Sprache sind auf einem M3 in etwa 0,3 Sekunden Text. Im Leerlauf braucht Inlaut keine Rechenleistung.

Lernt deine Wörter

Ersetzungen korrigieren, was die Erkennung immer wieder falsch schreibt. „Neue Zeile“ und „neuer Absatz“ funktionieren per Sprache.

So funktioniert es

  1. Inlaut starten. Beim ersten Mal lädt es das Sprachmodell (rund 670 MB, einmalig, mit Prüfsumme).
  2. Tastenkombination oder 🌐-Taste halten und sprechen.
  3. Loslassen. Der Text landet im aktiven Textfeld.
