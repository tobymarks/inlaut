# inlaut for Windows — 0.7.0-beta.9

Unsignierte Beta für Windows 10/11 x64 mit lokalem Diktat auf Deutsch oder Englisch.

## Sechs Korrekturen seit beta.8

- **Tastenkürzel:** Wird während einer gehaltenen Diktiertaste eine Tastenkombination wie Strg+A verwendet, wird die Aufnahme verworfen. Sie wird nicht in die gerade veränderte Auswahl transkribiert; ein noch wartender Aufnahmestart wird ebenfalls verworfen.
- **Zwischenablage:** Im optionalen Zwischenablage-Modus ersetzt das Diktat den bisherigen Inhalt und bleibt bis zum nächsten Kopieren erhalten. Damit kann inlaut keinen alten Inhalt wiederherstellen, bevor ein langsames Ziel das Einfügen verarbeitet. Erneutes Kopieren vor dem Einfügen kann dessen Inhalt weiterhin ändern. Die direkte Eingabe lässt die Zwischenablage unberührt.
- **Deutsches ß:** Die Korrektur erkennt Wortgrenzen auch neben Satzzeichen und Zeilenumbrüchen; diese Trennzeichen bleiben erhalten.
- **Autostart:** Speichern und Rücknahme bei einem Speicherfehler richten sich nach der tatsächlichen Windows-Registrierung, auch wenn die gespeicherte Einstellung davon abweicht.
- **Windows-Sitzungen:** Eine laufende Instanz in einer anderen Windows-Sitzung blockiert den Start nicht mehr. App und Installer prüfen dieselbe Sperre innerhalb der aktuellen Sitzung.
- **Modell-Download:** Ein hängender Ersatzdownload des deutschen Modells wird einschließlich der Datenübertragung nach spätestens zehn Minuten abgebrochen. Unvollständige Dateien werden entfernt; bestehende Modelldateien werden erst nach erfolgreicher Prüfung ersetzt.

## Prüfung und Installation

CoreSmoke einschließlich neuer ß-Fälle und SimulationSmoke sind lokal erfolgreich. Die Simulation prüft den produktiven Tastatur-Callback, eine simulierte Erkennungsausgabe durch die echte Textpipeline bis zu einem verzögerten Einfügeziel sowie Download-Abbruch und Fehlerfälle. App und UiSmoke wurden ohne Warnungen oder Fehler für Windows kompiliert. Die Windows-CI prüft zusätzlich den tatsächlichen Aufnahmeabbruch, das Einfügen in einen separaten um 1,5 Sekunden verzögerten Prozess, eine echte WAV-Aufnahme durch das Sprachmodell bis ins native Textfeld sowie Installation und Deinstallation. Das ist keine Abnahme mit echtem Mikrofon, Office oder mehreren Windows-Sitzungen; [Testumfang und Simulationsgrenzen](https://github.com/tobymarks/inlaut/blob/windows-v0.7.0-beta.9/windows/tests/Inlaut.SimulationSmoke/README.md).

Vor Installation von `inlaut-0.7.0-beta.9-windows-x64-setup.exe` inlaut vollständig beenden. **App und Installer bleiben unsigniert; Updates werden manuell von der Website installiert.** Windows kann eine Sicherheitswarnung anzeigen oder die Installation gemäß Gerätevorgaben blockieren. [Installationshinweise](https://inlaut.de/windows).

`SHA256SUMS.txt` und `BUILD.txt` dokumentieren Prüfsumme und Herkunft des Release-Installers.

Bekannte Grenzen bleiben bestehen: [leise Sprache](https://github.com/tobymarks/inlaut/issues/23), [Abstände und Großschreibung zwischen Diktaten](https://github.com/tobymarks/inlaut/issues/20), getrennte Sprachwahl sowie noch offene Windows-11-, Mikrofonwechsel-, Standby- und Bildschirmtests.

## Six fixes since beta.8

- **Keyboard shortcuts:** a shortcut such as Ctrl+A while holding the dictation key discards the recording and any queued recording start, preventing transcription into the changed selection.
- **Clipboard insertion:** this optional mode replaces the previous clipboard contents with the dictation and retains it until the next copy, avoiding restoration of old data before a slow target consumes the paste. Copying again before consumption can still change what is pasted. Direct input leaves the clipboard untouched.
- **German ß:** correction recognises word boundaries next to punctuation and line breaks while preserving those separators.
- **Launch at login:** saving and rollback after a save failure use the actual Windows registration rather than an outdated saved preference.
- **Windows sessions:** another session's running instance no longer blocks startup. The app and installer use the same lock within the current session.
- **Model download:** a stalled German-model recovery download now has a ten-minute limit covering the response body. Partial files are removed; existing model files are replaced only after verification succeeds.

## Validation and installation

CoreSmoke, including the new ß regressions, and SimulationSmoke pass locally. The simulation exercises the production keyboard callback, simulated recognition output through the real text pipeline to a delayed insertion target, and download cancellation/failures. The app and UiSmoke compile for Windows with no warnings or errors. Windows CI additionally checks actual recording cancellation, paste into a separate process delayed by 1.5 seconds, a real reference WAV through recognition to a native text field, and installation/uninstallation. This does not establish real microphone, Office or multiple-session acceptance; see [test scope and simulation limits](https://github.com/tobymarks/inlaut/blob/windows-v0.7.0-beta.9/windows/tests/Inlaut.SimulationSmoke/README.md).

Quit inlaut before installing `inlaut-0.7.0-beta.9-windows-x64-setup.exe`. **The app and installer remain unsigned; updates are manual downloads from the website.** Windows may warn or block installation under device policies. [Installation guidance](https://inlaut.de/en/windows).

`SHA256SUMS.txt` and `BUILD.txt` record the release installer checksum and build provenance. Known limits remain: quiet speech, spacing/capitalisation between dictations, separate language selection, and incomplete Windows 11, microphone reconnect, standby and display testing.
