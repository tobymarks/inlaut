# inlaut for Windows — 0.7.0-beta.11

Unsignierte Beta für Windows 10/11 x64 mit lokalem Diktat auf Deutsch oder Englisch. Wartungsversion mit neuer Audio-Bibliothek.

## Was sich seit beta.10 ändert

- **Audio-Bibliothek NAudio 3.3.0:** Die Mikrofonaufnahme läuft über NAudio 3.3.0 statt 2.2.1. Aufnahme, Erkennung und Textregeln sollen sich wie in beta.10 verhalten; neue Funktionen gibt es nicht. Wer mit beta.10 zufrieden ist, kann das Update auslassen.
- **Weniger Dateien:** NAudio 3 bringt die von inlaut nie genutzten Teile für ASIO und Windows Forms nicht mehr mit. Beim Update entfernt der Installer `NAudio.Asio.dll` und `NAudio.WinForms.dll`.
- **Lizenzen:** NAudio 3 liefert seinen Lizenztext nicht mehr im Paket mit. Der Installer enthält ihn jetzt als geprüfte Kopie aus dem NAudio-Quellcode, dazu Lizenz und Hinweise von System.Numerics.Tensors, das NAudio 3 mitbringt.

## Prüfung und Installation

Die Windows-CI prüft den Build, die gemeinsamen Textfälle mit dem Mac, die Ablauf-Simulation, die UI-Tests, die Umwandlung von WAV-Aufnahmen auf 16 kHz Mono, eine echte WAV-Aufnahme durch das englische Modell, Installation und Deinstallation sowie ein Update über das veröffentlichte beta.9 in einem selbst gewählten Ordner. **Diese Version wurde auf keinem echten Windows-PC und mit keinem echten Mikrofon getestet.** Falls die Aufnahme nicht funktioniert, bitte ein [Issue](https://github.com/tobymarks/inlaut/issues) anlegen und beta.10 wieder installieren: [beta.10](https://github.com/tobymarks/inlaut/releases/tag/windows-v0.7.0-beta.10).

Vor Installation von `inlaut-0.7.0-beta.11-windows-x64-setup.exe` inlaut über das Tray-Menü beenden. Der Installer verwendet den bisherigen Ordner; Einstellungen, Ersetzungen und Textbausteine bleiben erhalten. **App und Installer bleiben unsigniert; Updates werden manuell von der Website installiert.** Windows kann eine Sicherheitswarnung anzeigen oder die Installation gemäß Gerätevorgaben blockieren. [Installationshinweise](https://inlaut.de/windows).

`SHA256SUMS.txt` und `BUILD.txt` dokumentieren Prüfsumme und Herkunft des Release-Installers.

Bekannte Grenzen bleiben bestehen: [leise Sprache](https://github.com/tobymarks/inlaut/issues/23), [Abstände und Großschreibung zwischen Diktaten](https://github.com/tobymarks/inlaut/issues/20), getrennte Sprachwahl sowie noch offene Windows-11-, Mikrofonwechsel-, Standby- und Bildschirmtests.

Unsigned beta for Windows 10/11 x64 with local German or English dictation. A maintenance release with a new audio library.

## Changes since beta.10

- **Audio library NAudio 3.3.0:** microphone recording now runs on NAudio 3.3.0 instead of 2.2.1. Recording, recognition and text rules are meant to behave as in beta.10; there are no new features. If beta.10 works for you, you can skip this update.
- **Fewer files:** NAudio 3 no longer brings its ASIO and Windows Forms parts, which inlaut never used. When updating, the installer removes `NAudio.Asio.dll` and `NAudio.WinForms.dll`.
- **Licenses:** NAudio 3 no longer ships its license text in the package. The installer now includes it as a verified copy from the NAudio source, along with the license and notices of System.Numerics.Tensors, which NAudio 3 brings in.

## Validation and installation

Windows CI checks the build, the text cases shared with the Mac, the flow simulation, the UI tests, the conversion of WAV recordings to 16 kHz mono, a real reference WAV through the English model, installation and uninstallation, and an update over the published beta.9 in a folder of the user's choosing. **This version has not been tested on a real Windows PC or with a real microphone.** If recording does not work, please open an [issue](https://github.com/tobymarks/inlaut/issues) and reinstall [beta.10](https://github.com/tobymarks/inlaut/releases/tag/windows-v0.7.0-beta.10).

Quit inlaut from the tray menu before installing `inlaut-0.7.0-beta.11-windows-x64-setup.exe`. The installer uses the existing folder; settings, replacements and snippets are kept. **The app and installer remain unsigned; updates are manual downloads from the website.** Windows may warn or block installation under device policies. [Installation guidance](https://inlaut.de/en/windows).

`SHA256SUMS.txt` and `BUILD.txt` record the release installer checksum and build provenance. Known limits remain: [quiet speech](https://github.com/tobymarks/inlaut/issues/23), [spacing and capitalisation between dictations](https://github.com/tobymarks/inlaut/issues/20), separate language selection, and incomplete Windows 11, microphone reconnect, standby and display testing.
