# inlaut for Windows — 0.7.0-beta.8

**Öffentliche, unsignierte Beta für Windows 10/11 x64.**

Lokales Diktieren mit gebündelten deutschen und englischen Sprachmodellen.
Diktat- und Oberflächensprache sind unabhängig wählbar; ein Sprachwechsel
benötigt einen Neustart. Enthalten sind Sprachbefehle, eigene Ersetzungen und
Textbausteine sowie eine optionale Eingabe über die Zwischenablage.

## Download und Installation

- `inlaut-0.7.0-beta.8-windows-x64-setup.exe` herunterladen. Beide Sprachmodelle
  und die benötigte .NET-Laufzeit sind enthalten. Der Installer benötigt keine
  Administratorrechte.
- **Installer und App sind nicht digital signiert.** Windows kann „Der Computer
  wurde durch Windows geschützt“ oder einen unbekannten Herausgeber anzeigen.
  Wenn angeboten: „Weitere Informationen“ → „Trotzdem ausführen“, sofern du
  diesen Download bewusst von der offiziellen inlaut-Seite bezogen hast.
  Smart App Control oder Unternehmensrichtlinien können die Installation
  vollständig blockieren. Dafür keine systemweiten Schutzfunktionen ausschalten.
- Eine laufende inlaut-Version vor der Installation über das Tray-Menü beenden.
- **Updates manuell von der Website laden und installieren.** Der eingebaute
  Updater setzt vertrauenswürdige Signaturen voraus und kann diese Beta nicht
  aktualisieren. Die Signaturprüfung bleibt aktiv.
- Die SHA-256-Prüfsumme steht in `SHA256SUMS.txt`. Unter PowerShell lässt sie sich
  mit `Get-FileHash .\inlaut-0.7.0-beta.8-windows-x64-setup.exe -Algorithm SHA256`
  vergleichen. Eine Prüfsumme ersetzt keine digitale Signatur.

## Bekannte Grenzen

- Leise Sprache kann abgeschnitten werden ([#23](https://github.com/tobymarks/inlaut/issues/23)).
- Leerzeichen und Großschreibung zwischen getrennten Diktaten benötigen
  mitunter Korrekturen ([#20](https://github.com/tobymarks/inlaut/issues/20)).
- Deutsch und Englisch werden getrennt ausgewählt; gemischtsprachiges
  Diktieren bleibt Mac-only. Mehrzeilige Eingabe in manchen Office-/Browserfeldern
  benötigt den optionalen Zwischenablage-Modus.
- Windows 11, zusätzliche Bildschirmkonfigurationen, Mikrofonwechsel und
  Standby sind noch nicht vollständig geprüft. Englisch ist automatisch getestet;
  eine neue Abnahme auf einem physischen Windows-Gerät wird nicht behauptet.

**Public unsigned beta for Windows 10/11 x64.**

Local dictation with bundled German and English speech models. Dictation and
interface language can be selected independently; changing languages requires a
restart. Includes voice commands, replacements, snippets and optional clipboard
insertion. The installer includes the .NET runtime and needs no administrator rights.

**The installer and app are not digitally signed.** Windows may show
“Windows protected your PC” or an unknown-publisher warning. If offered, choose
“More info” → “Run anyway” only if you intentionally downloaded it from the official
inlaut page. Smart App Control or organization policies may prevent installation
entirely; do not disable system-wide protection to install this beta.

Close inlaut before installing. **Updates are manual downloads from the website**;
the in-app updater requires trusted signatures and cannot update this unsigned
beta. Verify the installer against the attached `SHA256SUMS.txt` if needed; a
checksum is not a digital signature.

Known limits: quiet speech can be cut off; spacing/capitalization between separate
dictations may need correction; mixed-language dictation is Mac-only. Multiline
input in some Office/browser fields requires opt-in clipboard insertion. Windows
11, additional display configurations, microphone changes and standby still need
broader testing. English has automated coverage, without a new physical-device
acceptance test.
